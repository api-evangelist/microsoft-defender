**Areas:** Cloud Security · Data Protection · Threat Intelligence · Email Security · Endpoint Security

- [Microsoft Defender XDR API](https://apis.io/apis/microsoft-defender/microsoft-defender-xdr-api/) — Unified extended detection and response API for automating workflows based on shared incident and advanced hunting tables across Microsoft security products.
- [Microsoft Defender for Cloud REST API](https://apis.io/apis/microsoft-defender/microsoft-defender-for-cloud-rest-api/) — REST API for unified security management and advanced threat protection across hybrid cloud workloads in Azure, other clouds, and on-premises.
- [Microsoft Defender for Identity API](https://apis.io/apis/microsoft-defender/microsoft-defender-for-identity-api/) — API for identity-based attack detection and investigation across on-premises Active Directory and hybrid environments, with sensor management via Microsoft…

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Microsoft Defender: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
